Kinoklip Flatpak

Unofficial Flatpak repository of Kinoklip (x86_64 and aarch64). Signed with GPG key 453FBF74E2F5069130AE55D01CFE07D9D0CBBE9A.

Stable (releases)

flatpak remote-add --user --if-not-exists kinoklip https://seniormatt.github.io/kinoklip-flatpak/kinoklip.flatpakrepo
flatpak install --user kinoklip org.kinoklip.Kinoklip

Or open org.kinoklip.Kinoklip.flatpakref with your software centre.

Nightly (development builds, untested)

flatpak remote-add --user --if-not-exists kinoklip-nightly https://seniormatt.github.io/kinoklip-flatpak/kinoklip-nightly.flatpakrepo
flatpak install --user kinoklip-nightly org.kinoklip.Kinoklip//nightly

Or org.kinoklip.Kinoklip-nightly.flatpakref.

Discover / GNOME Software

Download kinoklip.flatpakrepo (or kinoklip-nightly.flatpakrepo) and open it with the software centre (Discover: Settings, Add Source), or use the commands above.

Start it with flatpak run org.kinoklip.Kinoklip.
